## 2. الألوان (Design Tokens)

عرّف الألوان دائماً كمتغيرات CSS في `:root`، ولا تكتب قيمة لون مباشرة داخل المكوّنات.

```css
:root {
  --fiper-primary:     #TODO;  /* مؤقت: #2563EB */
  --fiper-primary-ink: #FFFFFF; /* لون النص فوق اللون الأساسي */
  --fiper-accent:      #TODO;  /* مؤقت: #F59E0B */
  --fiper-bg:          #FFFFFF;
  --fiper-surface:     #F8FAFC;
  --fiper-text:        #0F172A;
  --fiper-muted:       #64748B;
  --fiper-border:      #E2E8F0;
  --fiper-radius:      12px;
}
@media (prefers-color-scheme: dark) {
  :root {
    --fiper-bg:      #0B1120;
    --fiper-surface: #111827;
    --fiper-text:    #F1F5F9;
    --fiper-muted:   #94A3B8;
    --fiper-border:  #1F2937;
  }
}
```

القواعد:
- تباين النص مع الخلفية لا يقل عن **4.5:1** (معيار WCAG AA)، وللعناوين الكبيرة لا يقل عن 3:1.
- لون `--fiper-primary` مخصص للإجراء الرئيسي فقط، فلا تستعمله لكل الأزرار.
- لون `--fiper-accent` يُستعمل بقلّة، للتمييز فقط.

## 4. الشعار

- مسار الملف: `TODO` (مثلاً `assets/logo.svg`).
- اترك حول الشعار مساحة فارغة تساوي ارتفاع حرف "F" على الأقل.

- اكتب له نصاً بديلاً: `alt="فايبر"`.

## 5. نبرة الكلام (Tone of Voice)

- **واضحة ومباشرة**: جمل قصيرة، والفائدة قبل الميزة.
- **ودودة ومهنية**: خاطب الزائر بصيغة "أنت"، ولا تستخدم العامية الثقيلة.
- **واثقة بلا مبالغة**: لا تكتب "الأفضل في العالم" ولا "ثوري"، ولا أرقاماً غير موثّقة.
- لا تخترع أرقاماً أو شهادات عملاء أو شعارات شركاء. ضع مكانها `[placeholder]` واطلبها من المستخدم.

## 6. قواعد العربية والاتجاه (RTL)

- اكتب `<html lang="ar" dir="rtl">`، وفي النسخة الإنجليزية `lang="en" dir="ltr"`.
- استخدم الخصائص المنطقية في CSS، مثل `margin-inline-start` و`padding-inline` و`inset-inline-end`، بدل `left/right`.
- اقلب الأيقونات الاتجاهية (الأسهم) في RTL، ولا تقلب الشعار ولا الأيقونات غير الاتجاهية.
- الأرقام: استخدم أرقاماً موحّدة في الصفحة كلها، `TODO` (عربية 0-9 أو هندية ٠-٩).
